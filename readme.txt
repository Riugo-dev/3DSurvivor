「生き延びろ！！」

ただそれだけがコンセプトのゲームです。

GPUの設定に関して、本ゲームはインスタンシングや、ＧＰＵパーティクルのためにＧＰＵをを多用しますがこの時、初期設定だと
ＣＰＵ付属のＧＰＵを使用しゲームが重くなるケースがあります。それを解消するために、設定→システム→ディスプレイ→グラフィックで
デスクトップアプリの追加をクリックし本exeファイルを選択してください。その後、ｖを押しＧＰＵのユーザー設定という欄があるのでそこで
自機のＧＰＵ（学校のパソコンだとNVIDA）を選択してください。こうすることスムーズなゲーム体験ができます。

基本操作はWASDで移動
※xBoxコントローラーでは左スティック

カメラの回転を左右の矢印で可能
※xBoxコントローラーでは右スティック

強化画面では左右の矢印で強化対象を選択可能
また、enterで決定です。
※xBoxコントローラーではBボタン

攻撃はすべて自動で行われプレイヤーの移動の次第で当たったりします。

そうまさにヴァンサバを意識したゲームとなります。

また、ゲーム中にPを押すことでポーズすることも可能です。
※ポーズ中にenter(XboxコントローラーだとBボタン）でタイトルに戻ることができる

まだ開発中で最終的にスコアのランキングなどをつけたり、音をつけたりする予定です。

タイトル画面で上下の矢印で音量調整が可能です。
※xBoxコントローラーではDpadの上下

スコアランキングのスライドはスペースボタンまたはコントローラーでAボタンを押すとスクロールを飛ばし
一気にランキングが表示されます。

ランキング画面でＫ,Ｆ,Ｃのキーを長押ししながらＥｎｔｅｒを押すとスコアをリセットすることができます
（１位は残ります）
